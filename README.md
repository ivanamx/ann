# Ann Atelier — Landing Page

Landing premium bilingüe (EN/ES) para alta costura custom en **Houston, Texas**.

## Inicio rápido

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173). Cambia idioma con el botón **EN / ES** o `?lang=es`.

## Scripts

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Build de producción en `dist/` |
| `npm run preview` | Vista previa del build |

## Documentación del proyecto

Ver **[PROJECT_PLAN.md](./PROJECT_PLAN.md)** para visión, stack, SEO Houston, plan de fases y checklist 2026.

## Antes de producción

1. Actualizar dominio en `index.html`, `public/sitemap.xml`, `src/data/seo.ts`
2. Reemplazar teléfono, dirección y redes sociales reales
3. Añadir fotos reales del lookbook (WebP/AVIF)
4. Conectar formulario a email/CRM o Calendly
